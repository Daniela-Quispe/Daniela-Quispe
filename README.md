### 💫 Sobre Mí

🎓 **Estudiante de 4.º semestre de Ingeniería en Software** en la *Universidad Técnica de Ambato (UTA)*, Ambato - Ecuador 🇪🇨.

Me enfoco en el diseño y desarrollo de software de **alto rendimiento**, priorizando la **mantenibilidad del código**, la **separación de responsabilidades** y la **escalabilidad**. Apasionada por resolver problemas complejos mediante lógica estructurada y buenas prácticas.

- 🔭 **Actualmente trabajando en:** Frontend del *Sistema de Boletería y Transporte* aplicando **Clean Architecture**, enrutamiento dinámico por roles e integración con **Supabase**.
- 🌱 **En proceso de aprendizaje:** Arquitectura Limpia avanzada, **NestJS**, principios **SOLID** y microservicios.
- 💬 **Pregúntame sobre:** TypeScript, PHP (MVC), diseño DDL/DML en SQL Server y MySQL, y modelado de bases de datos.
- ⚡ **Intereses adicionales:** Redes de computadoras, simulación de tráfico (CSMA/CD) y desarrollo de APIs.

### 🏛️ Arquitectura & Metodología de Trabajo

- 📐 **Clean Architecture & SOLID:** Desarrollo desacoplado estructurado en capas (*Domain, Application, Infrastructure, Presentation*).
- 🔄 **Patrón MVC:** Implementación limpia en entornos PHP y bases de datos relacionales.
- 🔀 **Estrategia Git Flow & Conventional Commits:** Control de versiones ordenado (`feat:`, `fix:`, `docs:`, `refactor:`) para facilitación del trabajo colaborativo.
- 🗄️ **Modelado de BD Robusto:** Creación de esquemas relacionales, triggers, procedimientos almacenados, vistas y restricciones de integridad.
