### 🏛️ Filosofía de Arquitectura & Calidad de Software

<table>
  <tr>
    <td width="50%" valign="top">
      <h4>📐 Clean Architecture & SOLID</h4>
      <ul>
        <li><b>Desacoplamiento Estricto:</b> Separación en capas de <i>Domain</i>, <i>Application</i>, <i>Infrastructure</i> y <i>Presentation</i>.</li>
        <li><b>Independencia de Frameworks:</b> Lógica de negocio aislada de interfaces de usuario y motores de base de datos.</li>
        <li><b>Principios SOLID:</b> Inversión de dependencias, responsabilidad única y contratos bien definidos mediante interfaces.</li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h4>🗄️ Modelado de BD & Control de Versiones</h4>
      <ul>
        <li><b>Bases de Datos Relacionales:</b> Normalización hasta 3FN, diagramas ER, Triggers de auditoría, Vistas y Stored Procedures.</li>
        <li><b>Git Flow Standard:</b> Ramificación clara (<code>feature/</code>, <code>fix/</code>, <code>develop</code>, <code>main</code>).</li>
        <li><b>Conventional Commits:</b> Historial de cambios estandarizado (<code>feat:</code>, <code>fix:</code>, <code>docs:</code>, <code>refactor:</code>).</li>
      </ul>
    </td>
